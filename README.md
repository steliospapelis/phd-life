# PhD Life

A private, playful RPG layer for doctoral life. It turns ordinary academic survival into small wins, XP, milestones, sanity checks, achievements, titles, and labmate camaraderie.

## What’s inside

- Home dashboard for daily academic wisdom, sanity, and progress
- Task logging with XP and rewards
- PhD Journey milestones and achievements
- Custom avatar and title system
- Social labmate feed and citations
- Profile recap and activity history

## Project notes

This repository is for private project use and collaboration. Environment configuration, credentials, and deployment details are intentionally kept outside this README and out of version control.
